### [Visual Studio Code](https://code.visualstudio.com/)

#### Install using Git

If you are a git user, you can install the theme and keep up to date by cloning the repo:

```bash
git clone https://github.com/kneczaj/vcs-theme-dark.git ~/.vscode/extensions/kneczaj-theme-dark
cd ~/.vscode/extensions/kneczaj-theme-dark
npm install
npm run build
```

#### Activating theme

Run Visual Studio Code. The Theme will be available from `File -> Preferences -> Color Theme` dropdown menu.
